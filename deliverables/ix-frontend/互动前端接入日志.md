## 2. 实际改动

### 请求层（web/app.js）

- `requestJson` 遇 204 直接返回 `null`；非 2xx 抛 `RequestError(body.error, status)`，**保留服务端 409 错误码**，不再把 409 改写或自动重试。
- `requestWithRecovery` 仅对 `SESSION_REQUIRED`（重建会话一次）与 `STORAGE_UNAVAILABLE`（800ms 退避一次）自动恢复；透传超时。
- 错误文案表补全互动错误码：`TURN_EXPIRED`/`IMAGE_EXPIRED`/`CANDIDATE_EXPIRED`/`VERSION_CONFLICT`/`REQUEST_CONFLICT`/`MODEL_UNAVAILABLE`/`NOT_CONVERSATIONAL`/`IMAGE_REQUIRED`/`IMAGE_TOO_LARGE`/`UNSUPPORTED_IMAGE`/`INVALID_IMAGE`/`INVALID_TURN`/`INVALID_MEMORY` 等。
- 能力声明：`<html data-image="0">` → `SUPPORTS=['text']`；本地 fixture 因携带解码 WASM 由 `dev/server.mjs` 改写为 `data-image="1"`，云端精简包（`--no-wasm`）保持 `text`。

### 互动卡（web/app.js）

- 主按钮改为「开始一次互动」，`POST /api/interactions` 携带 `{budget,energy,scene,supports,request_id}`，每次逻辑操作新 UUID；按返回 `mode/state/expected_input` 渲染操作区。
- 聊聊/讨论：开场问 + 对话日志 + 文本输入 + 发送；连续两轮（第二轮用第一次回复的 version）；失败保留草稿与逐条重试；「换一个」用当前表单条件 + 新 UUID + `replaces`，失败保留旧卡且不提交反馈；「结束互动」DELETE 204 后收起输入；closed/expired 保留内容并提供「重新开始」（新互动 ID）。
- micro：第一步/耗时/喜欢/不喜欢/已完成/换一个；反馈绑定卡 ID；反馈响应**仅合并反馈字段**，不覆盖互动状态。
- 看图：拍照或选图 → 原始字节上传（JPEG/PNG/WebP，≤4MiB、每边≤4096px）→ `image_ref` → 以通过上传时 version 发起识图轮 → 词卡（英文/音标/释义/练习）后转文本输入；歧义先问再澄清或重拍；取消留在原卡。
- 幂等与竞态：重试复用同一 UUID/version/内容；`seq`+`current()` 守卫使换卡后迟到响应不污染新卡；版本推进后旧失败消息失去重试；`REQUEST_CONFLICT` 阻止同载荷重发；发送中防双击；IME 安全回车；全卡重建保留焦点。
- 存储不可用（503）：说明互动暂不可用并提供「看一条普通建议」回退到 `/api/recommendations`。

### 记忆（web/app.js / web/index.html）

- 候选确认三键：保存/改一下再保存/跳过，使用候选自身 version；过期/冲突收起按钮并提示。
- 设置区「我让 WhyNot 记住的事」：GET 列表（limit/offset、加载更多）、PATCH 编辑（版本冲突刷新列表并保留待修改文本）、DELETE 204 二次确认；区分空态与加载失败。
- 数据说明改写：条件/反馈/对话/确认过的记忆存服务端；对话发送给 AI 服务，只有点「保存」确认的话才成为记忆；此设备只存匿名会话/主题/引导。

### 样式（web/style.css）

### 浏览器实际操作（browser-use 真实点击/输入/上传）

- 看图黄金路径：上传真实 PNG → 词卡（stapler 音标释义练习）→ 文本练习轮，版本推进且词保留。
- 看图歧义：AI 先问哪一样 → 文本澄清复用原图 → 词卡；识别前重拍入口保留。
- 看图客户端校验：非图片类型、超 4MiB 均被拒并留在原卡。
- 看图失败重试：模型 5xx → 失败消息保留图片与重试键 → 恢复后重试复用同一请求 UUID 回到词卡。
- 看图换一个：换出非看图卡（新 ID、空消息）。
- 记忆演示：聊天触发候选 → 保存回执 → 设置列表可见 → 内联编辑升版本 → 二次确认删除 → 空态引导。
- 结束互动：DELETE 204 → 收起输入、保留消息、提供重新开始/换一个。
- 移动 375px 真实 iframe：聊聊与看图卡均无横向溢出，按钮热区≥44px（发送 48px、拍照 56px），词卡不溢出。
- 主页控制台仅余一条故意触发的 503（模型不可用测试），无应用脚本异常。

### 验证方法与局限

- 隐藏文件输入经 `DataTransfer` 触发其真实 `change` 处理函数，等价于选图；上传与续聊走真实接口。
- 假模型输出为固定桩，不等于真实视觉/语言模型识别质量。
- 移动宽度为真实 iframe 几何测量，不是仅改 body max-width。
- **内嵌浏览器视口隐藏，`take_screenshot` 返回 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE`，本阶段未产出截图证据**；移动布局以 iframe 真实几何断言代替目视截图，不冒称已截图。
- `acceptance.mjs` 的内置兜底断言扫描历史 DB 行，须在全新服务首跑；与互动套件共用长生命周期服务会因历史行污染误报（本阶段已重启服务复验通过）。
- 原生分享/剪贴板/系统主题分支沿用桩函数与 CSS 媒体模拟。

验票—

撕下票根，留个凭证

01

齿孔条 8px

撕口不在中间，在票头下方。暗示可撕，但不抢视线。

02

票头 44px

线路、站台、票号一行读完；等宽字保证数字永远对齐。

03

区间带 64px

从「现在」到「现在 +10′」。填时长，右侧立刻跟着变。

04

第一步区 102px

只给一件事：一句标题加最多两行做法，超出裁切；左侧橙线标注这是票的正文。

05

分钟刻度 32px

0–15 的尺，滑块停在所选时长上：位置本身就是承诺。

06

印章与票根

印章只在完成时落下；票根留三个轻动作，不写长句。

票根在移动端横排置底，≥1200px 才切为右侧竖排 88×152。

实施

落地拆分

三天做完 P0 就能上线；P1、P2 按预算排期，API 契约全程不变。

P01–2 天

整屏场景 + 填票

  • 场景层铺满 100svh，与票卡容器解耦
  • 票卡改为三道横线的表单：一次只展开一格
  • 浅色换清晨底图，不是给夜色加亮度
  • 保留全部 API 契约与 data-phase 命名
P12–3 天

美术与动效

  • 位图底图：16:9 昼 / 夜两套，1x 与 2x
  • 折叠：上一格 300ms 收成一行，下一格展开
  • 列车矢量动画，单次编排后收敛
  • 区间带随所选时长实时改写
P21–2 天

细节

  • 印章落地痕迹：轻微位移与纸纤维
  • 三套时间氛围：清晨 / 黄昏 / 深夜
  • 回到首页时记住上次条件，一键出票

验收清单

8 项
✓1440×900 首屏一屏内同时看到场景、文案与票，无纵向滚动
✓一次只出现一个问题；选完 300ms 内收成一行并展开下一格
✓三步未填完主按钮禁用；填完点一次即出票
✓切到清晨后列车与黄线仍可辨，不被遮罩洗白
✓IDLE 与 resting 态运行中动画数量为 0
✓reduced-motion 下无折叠动画、无列车动画，仍可完成
✓任一视口下，列车车身至少 25% 未被票据遮挡
✓503 时出现「本次不保存记录」且已填条件不丢

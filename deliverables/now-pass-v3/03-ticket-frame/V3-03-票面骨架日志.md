## 已实现

- web/app.js
  - 新增 `passCode(id)`：对 id 做确定性折叠（h*31+charCode，无符号 32 位），mod 36^4 后 base36 大写、不足 4 位补零。同一条建议重复渲染编号不变（反馈重渲染无跳变），换票后 id 变化则编号变化。
  - `buildCard()` 重构为票面结构：`article.card` → `ticket-head`（THIS PASS · NOW-XXXX＋有效，aria-hidden）＋ `ticket-body`（meta/标题/第一步/补充）＋ `ticket-sep`（分隔线，aria-hidden）＋ `ticket-stub`（条形码＋NOW-XXXX＋此刻作废，aria-hidden）＋ 操作区/完成行（整行横跨主券副券）。
  - 移除原标题下 `hr.card-sep`（方案票面九区无此分隔；无测试依赖，已 grep 确认）。
  - 说明：方案要求"id 缺失用会话序号"，实际 cardResult 校验保证 id 必为字符串，未引入会话计数器；空串 id 退化为 NOW-0000。偏差已记录。
- web/style.css
  - 新增 `--wn-mono` 令牌（ui-monospace,Consolas,monospace）。
  - `.card` 加 `position:relative;overflow:hidden`；`::before` 顶部锁齿边（radial-gradient 半圆序列 16px×8px repeat-x，洞色为页面底色）。
  - `.ticket-head`（min-height 28px＋发丝线）、`.ticket-code`（mono 12px、0.08em 字距）、`.ticket-valid`。
  - `.card h2` 改为 20px/700（--wn-t1 口径）、`-webkit-line-clamp:2` 两行省略。
  - `.ticket-body{padding-right:80px}` 给副券让位；`.ticket-stub` 绝对定位（top 64 / right 20 / bottom 80 / width 56）；`.ticket-bar` 条形码（repeating-linear-gradient 不规则条纹）；`.ticket-void` 此刻作废。
  - `.ticket-sep` 居右 88px 竖直虚线，`::before/::after` 12px 半圆缺口（页面底色，借 card overflow:hidden 裁出咬口）。
  - `.card-actions`、`.done-row` 加 `background:var(--wn-sheet)`，遮住穿过操作区的虚线段。
  - 窄容器退化：`@container (max-width:15em)` 内 `.ticket-body` 取消右让位、`.ticket-stub`/`.ticket-sep` 隐藏（200% 字号 2×2 布局下副券会让位重叠，直接退化为普通卡）。
  - 删除 ≤359px 媒体查询里冗余的 `.card h2` 覆盖（基准已改 1.25rem）。
- 未动：web/index.html（本批零改动）、产品红线语义（换一张只推荐、反馈绑定建议、完成幂等、分享不带标识）。

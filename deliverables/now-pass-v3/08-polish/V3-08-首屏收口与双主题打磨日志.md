## 3. 本批发现与处理

1. 只读审查发现主题单选外轮廓仍引用票面墨色。增加关于区焦点规则与双主题对比度断言，并通过实际 Tab 聚焦核对深色页底上的米白轮廓。
2. 首轮全量 UI 为 290 通过、1 失败，唯一失败为“首帧显式深色与页外文字同步”。逐项检查得到 dataset.theme=dark、引导颜色 rgb(167,177,201)，均正确；未加载 app.js 时，浏览器将 id=ask 暴露为 HTMLButtonElement，typeof window.ask 为 object，并非 undefined。
3. 修正的是测试前提：显式检查没有 app.js 外部脚本且 window.ask 不是函数，保留主题及精确颜色断言，没有修改正确的首屏实现，也没有放宽颜色要求。修正后七组全部重跑通过。
4. 截图发现既有完成态打孔 mask 会裁掉票卡外投影；本批未改该完成遮罩，浅色完成截图仍无明显外投影。普通票态的唯一浅色投影已验证，不把它写成所有完成态也可见投影。
5. 临时诊断中出现一次 about:blank iframe 的 onload 早于 srcdoc 导致无 guide 节点；诊断改为先设置 srcdoc 再插入，完成后移除。浏览器工具不接受内联 initScript 字符串以及大写 TAB，分别改为显式设置测试站点存储后刷新、使用 Tab。均为测试操作，不引入产品补丁；最终干净页面检查无报错。

## 2. 实际实现

- 完成票新增内联 SVG 双圆环印章：环间等宽 WHYNOT、章心“此”“刻”两行、固定 -8°。非完成到完成时播放一次 300ms 淡入和 scale(1.06→1)，不回弹、不循环。服务端确认不再重播；失败后恢复同一张完成票时也不重新盖章。
- 与乐观完成状态同步：票面 r=5px 径向 mask 透明圆孔、票头编号转橙、刻度虚线转实线。装饰 SVG 为 aria-hidden；印章不覆盖正文。
- 完成操作区改为不可点击的“已完成”状态文本，以及“换一张”“分享此刻”。状态可访问名称为“已完成，不可撤销”；焦点仍从原完成按钮交给状态文本，Tab 可到换票、分享。
- 保留既有乐观完成和反馈契约：在途不允许分享；成功后开放；失败恢复完成前的票面、操作与焦点。重复完成不新增请求，已确认完成不可撤销；陈旧反馈隔离保持原逻辑。
- 分享文案使用实际 card.minutes 而非预算：“刚完成一件约 X 分钟的小事……”。标题仍最多 40 个 Unicode 字符，链接仍只含 origin + pathname，不拼入 query/hash、真实编号或装饰票号。原生分享取消安静结束，Clipboard、传统复制和手动选中文本降级仍保留。
- 完成票存在时主出票按钮 visibility:hidden，保留原高度和间距，不与印章同屏、也不使页面跳动。换票退场期间仍隐藏；骨架接管后恢复为禁用的“出票中”；失败回显完成票时再次隐藏，重试与换票入口仍可达。条件控件一直可编辑。
- 卡片反馈重绘不再重播整卡 rise；仅新票保留入场。完成操作区保存旧区高度，并随同一张票跨失败回显保留；新推荐或回滚未完成时清除保高值。
- 窄容器中印章缩至 40px 并移到预留的票头右侧，隐藏有效徽标和副券；完成操作变为状态一行、两个按钮一行。正常容器为 64px 印章与三列操作区。至少 44px 按钮热区通过自动检查。
- 使用既有全局 reduced-motion CSS 关闭动效；减少动态下 exitCard 直接跳过退场。

实现定位：web/app.js:86（印章）、:202（完成操作）、:241（分享）、:331（重绘与保高）；web/style.css:69（主按钮隐藏）、:102–116（完成装饰与动效）、:152（完成操作）；dev/acceptance-ui.mjs:212（新增 completion 组）。

## 3. 本批发现并修复的问题

1. 刷新抑制类 animation:none 曾覆盖旧票 out 动画。改为 .card-refresh:not(.card-out)，新增断言直接检查完成票退场的 animation-name=out 和 160ms 时长。
2. 原保高只存在于 DOM，换票失败清空结果后重新渲染会丢失高度。新增 completionHeight 作为当前票的展示状态，测试“改条件后的两行操作区→完成→换票失败”仍保高。
3. 完成操作区建立定位绘制层，避免副券分隔线直接穿过操作文字。
4. 首次 completion 检查中，320px/200% 的焦点测试辅助函数主动滚动页面，导致视口坐标差异被误记为布局位移。改为 preventScroll 设置测试焦点后再取基准，随后直接调用完成处理；没有放宽几何断言。四档前后几何与 0/100/200/300ms 采样一致。

## 6. 未验、限制与延后项

- 真实手机、VoiceOver/TalkBack 有声读屏、系统级减少动态、原生分享面板与真实剪贴板权限未验。
- mask、:has、SVG textPath 在当前桌面浏览器通过；旧浏览器、其他引擎未测。mask 不可用时打孔可能不显示，不声明全平台兼容。
- 主按钮保留占位会留下空白，这是避免完成时页面跳动的本批取舍；未将隐藏改为 display:none。
- 深色页脚低对比、按压态对比、其他早期批次待补项不在本批冒称已修复；首屏与双主题打磨属于后续 V3-08。
- 完成票仍保持乐观即时呈现，服务器确认前不能分享；失败回滚不是撤销已确认完成。
- 非完成票仍用“换一个”，失败 404 的既有按钮文案也未改；本批“换一张”只在完成操作区应用，不扩大文案重构。
- raw 预算不达标及四项 gzip 对照超限明确保留，不能以自动化测试全绿等同于全部交付验收通过。

## 3. 安装资源实现与审计

- 图标使用 #101827 夜色底与 #F6F2E8 米白主体；不加入火车、轨道、站台或目的地等交通元素。
- SVG 三笔分别为带锁齿的上边、下边和中部短线；favicon 背景有圆角。
- PNG 背景完全不透明、不预裁圆角；系统是否应用蒙版由安装环境决定。manifest 只声明 purpose:any，不声称 maskable。
- manifest 的静态启动色不会随用户页面主题同步；页面仍默认跟随系统，显式浅／深色覆盖逻辑未改变。
- 生成器重复运行两次得到相同哈希；Pillow 独立解码验证尺寸，另行核验 PNG chunk CRC。三个 PNG 均为 4-bit indexed color，含 IHDR、PLTE、IDAT、IEND，无透明通道，所有像素 alpha=255。
- b4 在真实浏览器读取静态资源，将 SVG 主体应用同样的 0.8 缩放，与 PNG 进行全图 RGB 平均误差和 16 个端点／锁齿圆角局部区域比较。
- 全图平均误差阈值 <3 只证明主体近似一致，不等于像素完全一致；补充局部区域平均误差 <12 及 SVG roundcap／roundjoin 属性断言，防止小范围圆角退化被全图平均掩盖。
- PNG 的浏览器实绘、SVG 16／32／64 CSS px 预览均已目视查看；16px 下仍可识别三笔轮廓。此预览不是浏览器标签栏或原生系统安装界面验收。

详见 `icon-audit.json`、`ui-results.json` 和 `screens/01-install-assets.png`。
